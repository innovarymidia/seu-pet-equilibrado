# Seu Pet Equilibrado: Adestramento Canino em Cuiabá e Mato Grosso 🐾

Site oficial da **Seu Pet Equilibrado**, empresa referência em adestramento de cães e consultoria comportamental canina com reforço positivo em Mato Grosso e online para o mundo.

## 👥 Especialistas e Equipe
- **Adestrador João Eduardo:** Responsável pelos atendimentos presenciais domiciliares em Cuiabá e Várzea Grande, MT.
- **Adestradora Nicolle:** Responsável pelas consultorias comportamentais online para famílias de qualquer localidade.

## 🎨 Identidade Visual e Recursos
- **Paleta de Cores:** Mogno e chocolate quente (`#351515`), rosa terracota acolhedor (`#D9B6AC`) e fundos claros elegantes (`#FAF6F4`).
- **Interatividade:** Rastro fluido de patinhas em canvas a 60fps acompanhando o cursor.
- **Diagnóstico Rápido:** Quiz interativo em 3 etapas com encaminhamento inteligente para o WhatsApp oficial.
- **SEO Local e GEO:** Dados estruturados Schema.org completos para motores de busca e modelos de inteligência artificial.

## 🚀 Como Executar Localmente
Para abrir o projeto localmente com qualquer servidor estático:
```bash
# Com Python 3
python -m http.server 8080

# Ou com Node.js npx serve
npx serve
```
Acesse no navegador: `http://localhost:8080/`
